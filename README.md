# Lite Browser 下载

Lite Browser 是轻量浏览器，支持从链接安装用户脚本。浏览器启动后可直接打开网页或搜索，用户脚本可在 **工具 → 用户脚本** 中管理。

## v0.3.1

- Android 8.0 及以上，支持 ARM64 和 x86_64。已签名，可从 0.3.0 覆盖升级。[下载 Android APK](https://github.com/zacharyzj/lite-browser-releases/releases/download/v0.3.1/LiteBrowser-Android.apk)

## v0.3.0

- Windows 10 / 11 x64。下载便携 EXE 后运行，需系统提供 WebView2 Runtime。[Windows x64](https://github.com/zacharyzj/lite-browser-releases/releases/download/v0.3.0/LiteBrowser-Windows-x64.exe)
- Android 8.0 及以上，支持 ARM64 和 x86_64。正式签名 APK 可覆盖升级公开版 0.2.2。[Android APK](https://github.com/zacharyzj/lite-browser-releases/releases/download/v0.3.0/LiteBrowser-Android.apk)

## v0.2.2

- Windows 10 / 11 x64。下载 EXE 后运行，需系统提供 WebView2 Runtime。[Windows x64](https://github.com/zacharyzj/lite-browser-releases/releases/download/v0.2.2/LiteBrowser-Windows-x64.exe)
- Android 8.0 及以上，支持 ARM64 和 x86_64。下载并打开正式签名 APK 安装。[Android APK](https://github.com/zacharyzj/lite-browser-releases/releases/download/v0.2.2/LiteBrowser-Android.apk)
